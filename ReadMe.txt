To run the Code you have to follow the steps below:

1. Install Python 3.12.10

2. Setting up a virtual Environment:

    in VS Code press CTRL + Shift + P
    Enter Python: Create Environment
    Choose the Python 3.12 Interpreter
    skip Package installation

3. Installing Dependencies:
    
    Open a new Terminal
    Make sure you are in your virtual Environment, you can see this if there is a (.venv) at the beginning of the Command Line
    type pip install -r requirements.txt

4. Run the Code

    You can now run the Code
    It is possible that you need to change the index in the CV2 Variable to make sure it uses the right camera input.
